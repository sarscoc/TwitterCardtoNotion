GitHub接続設定

Cloudflareは使用しません。カード情報と画像はGitHubへ保存し、GitHub Actionsがカードページを生成します。

GitHubでFine-grained personal access tokenを作成し、このリポジトリだけを選択してください。必要な権限は Contents: Read and write と Actions: Read and write です。トークンはこのタブのセッション中だけ保存され、タブを閉じると消えます。

設定手順：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
